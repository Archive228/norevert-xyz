# NV-01 parts viewer assets

The 55 shell meshes derive from RoboParty rpo_appearance, commit 4bf61434f4925fbd9076a82d3639b0d6e7133f60.

https://github.com/Roboparty/rpo_appearance/tree/4bf61434f4925fbd9076a82d3639b0d6e7133f60

See SHELL-LICENSE. Source meshes were clustered for display, rotated to Y-up, centered, quantized and compressed. These are viewing assets, not replacement manufacturing files. The index records original and display triangle counts and source links.

The head assembly and electronics are Norevert explanatory 3D models. The proposed head layout has not been validated for physical fit. Subcomponents shown inside purchased modules are included in the corresponding module allowance, not additional purchases.
